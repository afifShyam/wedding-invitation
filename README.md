# 💍 Wedding Invitation Website

A beautiful and interactive wedding invitation web application — complete with countdown, event details, RSVP form, map integration, and carousel for guest wishes.

## 🌸 Features

- 🌼 Romantic UI with animated floral background
- 💌 RSVP form with guest name, attendance, message
- ⏳ Real-time countdown to the wedding day
- 🗺️ Embedded Google Maps location with navigation links
- 💬 Wishes carousel with auto-scrolling
- 💫 Smooth animations using Framer Motion
- 📱 Fully responsive and mobile-friendly

## 🛠️ Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Chakra UI](https://chakra-ui.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [React Multi Carousel](https://www.npmjs.com/package/react-multi-carousel)
- [TypeScript](https://www.typescriptlang.org/)
